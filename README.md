# Cinergy Pulse Template

A multi-page, critic-forward film and series website inspired by Rotten Tomatoes, The Hollywood Reporter, IMDb, and TMDB—styled for a futuristic 2026 aesthetic.

## Pages
- **index.html** – hero slider, critic hot lists, streaming spotlights, and latest reviews.
- **movies.html** – film index showcasing premieres, festival picks, and now-showing titles.
- **tv.html** – series radar with bingeable highlights and quick review links.
- **article.html** – cinematic review layout with an embedded YouTube trailer, rich details, and sidebar intel.

## Running locally
Use any static server. From the repository root:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.
